常见问题

Deep Desk 和 Claude Code 是什么关系？

Deep Desk = Claude Code + 可视化 Web 界面 + DeepSeek 后端。底层是 Claude Code 的能力，但加了一个漂亮的网页界面让你在浏览器里用，后端跑的是 DeepSeek 模型。不用翻墙、不用注册 Anthropic 海外账户。

有界面吗？和纯命令行有什么区别？

有。装好 Deep Desk 后浏览器打开 localhost:3456，就能看到一个深色主题的聊天界面——支持多标签对话、一键复制消息、权限审批卡片。你也可以在终端输入 ccb 用命令行模式，两个都能用。

我还是需要自己注册 DeepSeek 吗？

是的，需要你自己的 DeepSeek API key。不过不用担心——DeepSeek 注册只需手机号，免费额度够用很久，我们在安装时会一步一步引导你完成。你要做的只有：打开网页 → 手机注册 → 复制粘贴 key。

买了能用多久？

基础版和 Pro 版都是一次购买、永久使用。Deep Desk 只是工具和配置——API 调用走你自己的 DeepSeek 账户，费用由 DeepSeek 直接收取（新用户通常有免费额度）。

能在几台电脑上用？

基础版 1 台，Pro 版 3 台。License 绑定设备硬件指纹，不能无限复制给其他人。

Windows 能用吗？

能。Windows 10/11 的 x64 和 ARM64 都支持，双击 install.bat 就能装。
