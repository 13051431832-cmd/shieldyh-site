常见问题

Deep Desk 和 Claude Code 是什么关系？

Deep Desk 包含 Claude Code 完整功能的实现，且使用国内的 DeepSeek 作为核心引擎，国内直连。你不需要解决翻墙、海外手机号、命令行配置这些麻烦——装好打开浏览器就能用。

需要记命令吗？怎么用？

不需要。装好后电脑会自动打开一个聊天页面，像微信一样打字就能和 AI 对话。同时可以聊好几个话题，聊完记录自动保存。你也可以在终端输入 ccb 用键盘操作模式。

我还是需要自己注册 DeepSeek 吗？

是的，需要你自己的 DeepSeek API key。不过不用担心——DeepSeek 注册只需手机号，免费额度够用很久，我们在安装时会一步一步引导你完成。你要做的只有：打开网页 → 手机注册 → 复制粘贴 key。

能用多久？

免费版永久免费，Pro 版一次获取永久使用。Deep Desk 只是工具和配置——API 调用走你自己的 DeepSeek 账户，费用由 DeepSeek 直接收取（新用户通常有免费额度）。

能在几台电脑上用？

免费版 1 台，Pro 版 3 台。License 绑定设备硬件指纹，不能无限复制给其他人。

Windows 能用吗？

能。Windows 10/11 的 x64 和 ARM64 都支持，双击 install.bat 就能装。
